Code Assistant on Steroids: When Everything Is Code

Alternative title: "Everything Is Code Now. Your Coding Assistant Already Knows."

Abstract

Your coding assistant writes code. Claude Code, GitHub Copilot, Codex: that part is settled. The more interesting question is why we keep it locked inside the editor. The same assistant can build your slide deck, draw the images and diagrams for it, deploy the application it just wrote, cut a video, sort your inbox and dim the lights in your living room.

That is no accident. We have spent a decade turning our work into text in a repository: infrastructure as code, pipelines as code, configuration as code, docs as code, diagrams as code, slides as code. That is exactly the material a coding assistant is good at. It is not that a coding assistant happens to be useful beyond coding. Almost everything has quietly become coding.

From there it is a short step to everything else. An assistant that can run a command can talk to anything with an API, and with a bit of browser automation to plenty of things without one. Keeping dependencies current, triaging mail, running the smart home, making sure the stuff you own keeps working: it is all the same loop. Which leads to the punchline for this audience: as a developer with a coding assistant, you don't need OpenClaw or Muse. You already have the more capable tool.

Slides are kept to a minimum. The assistant works live on stage, on real examples. And if you think you already push yours to its limits, I'm fairly sure you'll still walk away with an idea or two.

Key Takeaways

- Why "everything as code" turns your coding assistant into a general-purpose assistant.
- Concrete non-coding workflows you can copy on Monday: slides, images, diagrams, deployments, video, mail and home automation.
- How to connect your assistant to systems with an API, and to the ones without one via browser automation.
- Why a developer with a coding assistant doesn't need a separate general-purpose AI assistant.
- (Optional, only if you cover it) How to give an assistant access to your mail and your home without regretting it.
