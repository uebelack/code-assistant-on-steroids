Code Assistant on Steroids: Wenn alles Code ist

Alternativer Titel: "Alles ist jetzt Code. Dein Coding-Assistent weiss das schon."

Abstract

Dein Coding-Assistent schreibt Code. Claude Code, GitHub Copilot, Codex: das ist geklärt. Die interessantere Frage ist, warum wir ihn weiter im Editor einsperren. Derselbe Assistent baut Dir die Präsentation, zeichnet die Bilder und Diagramme dazu, deployt die Anwendung, die er gerade geschrieben hat, schneidet ein Video, sortiert Dein Postfach und dimmt das Licht in Deinem Wohnzimmer.

Das ist kein Zufall. Wir haben ein Jahrzehnt damit zugebracht, unsere Arbeit in Text in einem Repository zu verwandeln: Infrastructure as Code, Pipelines as Code, Configuration as Code, Docs as Code, Diagrams as Code, Slides as Code. Genau damit kann ein Coding-Assistent umgehen. Es ist nicht so, dass ein Coding-Assistent zufällig auch jenseits von Code nützlich ist. Fast alles ist still und leise zu Coding geworden.

Von da an ist es nur ein kleiner Schritt zu allem anderen. Ein Assistent, der ein Kommando ausführen kann, redet mit allem, was eine API hat, und mit etwas Browser-Automatisierung auch mit vielem, was keine hat. Abhängigkeiten aktuell halten, Mails sortieren, das Smart Home betreiben, dafür sorgen, dass das eigene Zeug weiter läuft: alles dieselbe Schleife. Was zur Pointe für dieses Publikum führt: als Entwickler mit einem Coding-Assistenten brauchst Du weder OpenClaw noch Muse. Du hast das mächtigere Werkzeug schon.

Die Slides halte ich knapp. Der Assistent arbeitet live auf der Bühne, an echten Beispielen. Und wenn Du meinst, Deinen schon am Limit zu fahren, bin ich recht sicher, dass Du trotzdem eine oder zwei Ideen mitnimmst.

Key Takeaways

- Warum "everything as code" Deinen Coding-Assistenten zum Allzweck-Assistenten macht.
- Konkrete Workflows jenseits von Code, die Du am Montag übernehmen kannst: Slides, Bilder, Diagramme, Deployments, Video, Mail und Hausautomation.
- Wie Du Deinen Assistenten an Systeme mit API anbindest, und per Browser-Automatisierung an die ohne.
- Warum ein Entwickler mit Coding-Assistenten keinen separaten Allzweck-KI-Assistenten braucht.
- (Optional, nur falls Du es behandelst) Wie Du einem Assistenten Zugriff auf Deine Mails und Dein Zuhause gibst, ohne es zu bereuen.
